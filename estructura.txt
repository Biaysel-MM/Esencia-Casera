
RESUMEN DEL PROYECTO ESENCIA CASERA (ACTUALIZADO)
Esencia Casera es una aplicación web Vue.js integral de planificación y gestión culinaria diseñada para familias y cocineros domésticos. El sistema permite a los usuarios registrar todos los ingredientes disponibles en su despensa y, mediante algoritmos inteligentes, genera automáticamente recetas personalizadas que pueden preparar con lo que ya tienen en casa. La aplicación incluye un planificador semanal interactivo, sugerencias basadas en condiciones climáticas, sistema de votación familiar para decidir menús, gestión de lista de compras automatizada y seguimiento de fechas de vencimiento de ingredientes.

La plataforma se destaca por su guía paso a paso con imágenes para cada receta, facilitando el proceso culinario incluso para principiantes. Con roles diferenciados (administrador y familiares), soporta dinámicas familiares colaborativas donde todos pueden votar por las comidas de la semana. La integración completa con Supabase asegura persistencia de datos en tiempo real, mientras que la interfaz intuitiva y visualmente atractiva mantiene una experiencia de usuario fluida y accesible para toda la familia.

Resumen de la Base de Datos "Esencia Casera" (ACTUALIZADO)
Tablas Principales y sus Relaciones

1. Tabla Central: profiles
Propósito: Perfiles de usuarios con autenticación completa
Campos clave: id (UUID), full_name, role, family_code
Relaciones: Referenciada por casi todas las otras tablas como user_id o created_by

2. Catálogo de Ingredientes (ingredients)
Propósito: Catálogo maestro de ingredientes disponibles
Categorías: verduras, frutas, proteínas, granos, lácteos, condimentos, bebidas, otros
Relaciones: Referenciada por recipe_ingredients, user_pantry, shopping_list_items

3. Sistema de Recetas (recipes + recipe_ingredients + comentarios_de_la_receta)
recipes: Almacena recetas con pasos en formato JSONB, categorías, tiempo de preparación

recipe_ingredients: Tabla de unión que relaciona recetas con ingredientes y sus cantidades
comentarios_de_la_receta: Sistema de comentarios en recetas con:
Me gusta (like/unlike en comentarios)
respuestas_de_comentarios (respuestas anidadas a comentarios)
Características: Calificaciones, tags, visibilidad pública/privada

4. Gestión Personal (user_pantry + shopping_lists + despensa_del_usuario)
user_pantry / despensa_del_usuario: Despensa personal de cada usuario con fechas de caducidad
shopping_lists + shopping_list_items / articulos_de_la_lista_de_compras: Listas de compras con seguimiento de estado
Vista: vista_de_ingredientes_que_caduca (ingredientes próximos a vencer) — IRRESTRICTO

5. Planificación Semanal (weekly_planner + planned_meals + comidas_planificadas)
weekly_planner: Planificador semanal por usuario
planned_meals / comidas_planificadas: Comidas específicas asignadas a días y tipos (desayuno, almuerzo, cena)
Vista: vista_de_las_comidas_de_hoy — IRRESTRICTO
Backup temporal: reserva_de_comidas_planificadas_temporales — IRRESTRICTO

6. Funcionalidades Sociales y Colaborativas (families + encuestas familiares + votos familiares)
families: Grupos familiares con código único
encuestas familiares: Sistema de encuestas para decisión familiar
votos familiares / family_votes: Votación familiar para recetas semanales
opciones_de_encuesta: Opciones disponibles en cada encuesta
votos_de_la_encuesta: Registro de votos emitidos
familias: Gestión de núcleos familiares

7. Interacción Usuario (favorites + cooking_history + favoritos + historia de la cocina)
favorites / favoritos: Recetas marcadas como favoritas
recetas favoritas del usuario: Relación usuario-recetas favoritas
cooking_history / historia de la cocina: Historial de recetas preparadas con calificaciones
Backup temporal: copia_de_seguridad_de_favoritos_temporales — IRRESTRICTO

8. Sistema de Notificaciones (notifications)
Propósito: Notificaciones personalizadas por usuario
Tipos: expiry (caducidad), recipe, shopping, family, weather, system

9. Sugerencias Inteligentes (weather_suggestions + sugerencias meteorológicas + planificador_semanal)
weather_suggestions / sugerencias meteorológicas: Sugerencias de recetas basadas en condiciones climáticas
planificador_semanal: Herramienta de planificación de menús por semana

10. Vistas de Acceso Irrestricto (RLS desactivado)
Vista	Propósito
vista_de_recetas_disponibles	Recetas que se pueden preparar con despensa actual
vista_de_ingredientes_que_caduca	Ingredientes próximos a caducar
vista_de_las_comidas_de_hoy	Comidas planificadas para el día actual
copia_de_seguridad_del_historial_de_coccion_temporal	Backup temporal del historial de cocción
copia_de_seguridad_de_favoritos_temporales	Backup temporal de favoritos
reserva_de_comidas_planificadas_temporales	Backup temporal de comidas planificadas

Características Clave
Seguridad (RLS)
Políticas de Row Level Security en todas las tablas
Usuarios solo ven/modifican sus propios datos
Excepciones: ingredients (todos pueden ver, solo admins modificar)
Vistas IRRESTRICTO: Acceso público sin RLS para vistas funcionales y backups temporales

Triggers para mantener consistencia

Flujo Principal de Datos (Actualizado)
Usuario se registra → Se crea perfil automáticamente
Datos de prueba se inicializan automáticamente (despensa, planificador, etc.)
Usuario gestiona despensa → Sistema sugiere recetas disponibles (vista_de_recetas_disponibles)
Planificación semanal → Generación automática o manual de menús
Familia vota mediante encuestas → votos_familiares y opciones_de_encuesta
Compra ingredientes → Listas de compras integradas con despensa
Cocina recetas → Se registra en historia_de_la_cocina, se actualizan calificaciones
Comentarios y respuestas → Interacción social en recetas con sistema de "me gusta"
Backups temporales → Copias de seguridad automáticas con acceso irrestricto
